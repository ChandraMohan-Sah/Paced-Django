# 🌐 Comprehensive Django Learnings

Welcome to the **Comprehensive Django Learnings** portal! This project demonstrates practical Django concepts using individual modules, each crafted with real-world functionality and best practices.

🟢 Live Project: [Visit Now](https://collegeproject.pythonanywhere.com/)



## 🧩 Features Covered

Each card on the homepage represents a standalone Django functionality:
``` bash
| 🧩 Module Title                       | 🌟 Description                                                  |
|-------------------------------------- |-----------------------------------------------------------------|
| 🌍 Multpage Navigation                | Implement multi-page templates with Django views and routing.   |
| 📝 Simple Form Submission             | Basic form handling with validation and feedback.               |
| ✉️ Contact Form [SMTP]                 | Send emails using SMTP integration for contact forms.           |
| 📤 File Uploads                       | Upload and manage files in the project.                         |
| 🔍 Pagination, Filter, Search, Order  | Handle list views with advanced query features.                 |
| 🎓 Capstone 1: Portfolio              | A complete portfolio site built as a final capstone.            |
| 🔐 Authentication [2-types]           | Includes session-based and token-based authentication.          |
| ⏳ Session Management                 | Track user sessions, store temporary state.                     |
| ➡️ Payment Gateway                     | Simulate or integrate payment functionality.                    |
| 🔗 DRF: IMDB Clone                    | REST API using Django REST Framework.                           |
| 🚀 ML Model Integration               | Embed a machine learning model for predictions or classification.|
```



---

## ⚙️ Tech Stack

- **Backend**: Django
- **Frontend**: HTML, CSS, W3.css, Server-side Template
- **Other Tools**: SMTP, Sessions , ML Model

## 🚀 How to Run Locally

```bash
git clone git@github.com:ChandraMohan-Sah/Paced-Django.git
cd django-learning-project
pip install -r requirements.txt
python manage.py runserver
```
