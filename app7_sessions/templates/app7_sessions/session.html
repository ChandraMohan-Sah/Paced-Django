What is a Session ?

  • An "ongoing connection" between a client(browser) and server.
  • Data stored in a session persists as long as the session is active.

Demonstration Clarification

  • First loggedin user should keep product on their cart. As for now, data is maintained to be stored both on database and session.
  • Now,in one column, data is retrieved from database, while in the other column, data is retrieved from the session. Data stored in the database remains persistent and does not disappear even after the session expires.
